Start learning in three steps

1. Choose a subject

Open the classroom and select a learning level and subject. The learning level currently changes the label; lessons are shared samples, not certified grade-level material.

2. Read and practice

Read a short lesson, open its original source, and try the quiz. Your progress is saved only in this browser, where storage is available.

3. Choose your device

Android: In Chrome, open the HTTPS website. Choose the browser's Install app or Add to Home screen option if available. Installation depends on browser and deployment support.

Meta Quest: Open the experimental Quest lab in Quest Browser over HTTPS. If supported, select Enter Meta Quest VR. Press a controller trigger to switch stations and select Exit VR to leave. Use the desktop fallback if immersive VR is unavailable.

Need help?

If the install option is missing, use the website directly. If VR is unavailable, use the regular lessons. This is a supervised educational preview, not a complete school or a generative AI tutor. No account is required.
