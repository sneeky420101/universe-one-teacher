# Universe AI One Teacher — Private Release Candidate Gate

Owner: VOLTFRAME Studios. Status: **PRIVATE / NOT APPROVED FOR PUBLICATION**.

## Evidence rules
- A passing source or server test is **not** evidence that buttons, mobile touch, VR, school accounts, payment, or device installation work.
- Each requirement must be marked separately: requested, designed, coded, tested, integrated, deployed. Mark tested only with a recorded test and outcome.
- No automatic public release, merge, store submission, advertising, public URL activation, or enrollment. Explicit owner approval is mandatory.

## Required pre-launch acceptance scenarios
1. **Core navigation:** open homepage, gameplay hub, each campus, lesson, privacy, college, and trades route; check every link and browser back behavior.
2. **Workshop controls:** select all four workshops and all three stations; verify keyboard, mouse, touchscreen, zoom, rotation, station buttons, focus and screen-reader names.
3. **Learning journey:** complete all guided steps, adjust and run an experiment, choose a practice decision, answer incorrectly, retry, answer correctly, and verify mastery display.
4. **Recovery:** reload and revisit every station; verify guided progress, practice, answers, experiment outcomes and slider values. Reset experiment and confirm the assessment gate relocks.
5. **Accessibility:** keyboard-only path, 200% zoom, narrow mobile viewport, reduced motion, contrast, speech controls and speech unsupported fallback.
6. **Security/privacy:** invalid routes, unsafe methods, content-security headers, storage disclosure, child-data handling, account and deletion policies.
7. **Device matrix:** Android Chrome physical touch, iOS Safari physical touch, Windows desktop Chrome/Edge, macOS Safari, and Quest headset/controller/exit tests; attach actual device/OS/browser versions and evidence.
8. **School readiness:** verify real teacher/student roles, school consent, assessments, curriculum evidence, accessibility and internationalization separately. Do not represent a prototype as accredited.
9. **Distribution:** signed Android bundle, Play policy review, developer contact, privacy review, store screenshots, offline/update handling and HTTPS origin.
10. **Owner approval:** all critical issues closed, verified evidence recorded and explicit final authorization **before** any publication.
